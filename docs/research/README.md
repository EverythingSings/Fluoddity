# Research Notes

This folder holds imported design and product research that informs Fluoddity's move from art toy toward game-shaped work.

## Game Design Foundations

- [From Pong to Balatro: What Fifty Years of Great Games Teach Us About the Foundations of Fun](foundations-of-fun.md)
- [Source PDF](foundations-of-fun.pdf)

Use this as reference material, not a hard spec. The strongest takeaways for Fluoddity are: easy to learn and hard to master, tight action-feedback-reward loops, meaningful choices, flow-state tuning, and fun as learnable pattern mastery.
